## ✨ О проекте

**Neon Clock** — это неоновые мировые часы, написанные на Python с использованием Tkinter.  
Один файл, никаких сложных зависимостей — просто запусти и наслаждайся.  
Встречает кинематографичной заставкой с матричным дождём, а дальше открывает целый мир времени.

## 🎬 Заставка

При запуске приложение встречает **кинематографичной заставкой** длиной 8 секунд:

1. **0.0 сек** — Матричный дождь символов падает по экрану
2. **1.0 сек** — Появляются буквы **N E O N** (по одной с неоновым свечением)
3. **3.0 сек** — Печатается **C L O C K**
4. **4.0 сек** — Вокруг названия вырастают кольца
5. **5.0 сек** — Печатается предыстория
6. **6.5 сек** — Появляется **Created by Web0f**
7. **7.2 сек** — Всё готово, ждёт нажатия Enter
8. **После Enter** — вспышка → открываются часы 🎉


## 🎮 Управление

| Действие | Как |
|---|---|
| 🌍 **Выбор города** | Введи название в поиск → кликни по городу в списке слева |
| 🔄 **Сменить режим** | Кнопка «🌍 Города / 🕐 Пояса» |
| 🎨 **Выбор темы** | Комбобокс «Тема:» сверху |
| 🎲 **Случайная тема** | Кнопка 🎲 рядом с темами |
| 🌈 **Радужный режим** | Кнопка 🌈 — цвета плавно перетекают |
| ✨ **Эффект фона** | Комбобокс «Эффект:» (звёзды/снег/огонь/листья/выкл) |
| 🌐 **Язык** | Комбобокс «Язык:» (ru/en/de/es) |
| 🔔 **Будильник** | Кнопка 🔔 |
| ⏱ **Секундомер/Таймер** | Кнопка ⏱ |
| 🌙 **Астро-блок** | Кнопка 🌙 |
| 📝 **Заметки** | Кнопка 📝 |
| 🖥 **Свернуть в трей** | Кнопка 🖥 |
| 🖥 **Полный экран** | **F11** — вкл/выкл, **Esc** — выход |

## 🛠 Технологии

| Компонент | Назначение |
|---|---|
| **Python 3.9+** | Основной язык |
| **Tkinter** | GUI (встроен в Python) |
| **zoneinfo** | Работа с часовыми поясами IANA |
| **geonamescache** | База 25 000+ городов мира |
| **timezonefinder** | Определение TZ по координатам |
| **tzdata** | База часовых поясов для Windows |
| **pystray + Pillow** | Иконка в системном трее (опционально) |
